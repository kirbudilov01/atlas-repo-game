# 00 — Overview

## Product Definition

Atlas Repo Game / Ecosystem OS is a Telegram Mini App that combines idle tycoon gameplay, a founder-life digital twin, product discovery, rewards, referrals, funding missions, and future utility economy.

It is not a FabricBot dashboard. FabricBot powers payments, subscriptions, rewards, promo codes and partner accounting under the hood.

## Core System

```text
FabricBot -> money/access/partner infrastructure
AtlasRepo -> knowledge/discovery catalog
Want2View -> commercial trend intelligence product
Game -> living world and user-facing operating system
```

## MVP Promise

In the first session the user should:

- understand the room;
- click Atlas Core;
- get Compute;
- buy a generator;
- complete an AtlasRepo quest;
- see real reward potential;
- get a referral link;
- understand future locked spaces.

## Assumptions

- Telegram Mini App is the primary platform.
- First version focuses on owned ecosystem projects.
- Tokens, NFTs and third-party projects are future layers.
- Real rewards must be limited and abuse-resistant.
