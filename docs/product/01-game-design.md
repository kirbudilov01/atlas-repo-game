# 01 — Game Design

## World Layers

| Layer | Purpose | MVP |
|---|---|---|
| Our Room | founder story hub | working |
| My Room | personal AI factory | locked/preview |
| Network | social/mastery layer | locked/preview |
| Project Worlds | product spaces | AtlasRepo/Want2View terminals |

## First Session

1. User opens app.
2. User chooses role or skips.
3. User enters Our Room.
4. Atlas Core pulses.
5. User clicks and earns Compute.
6. User buys Compute Generator.
7. User completes AtlasRepo First Scan.
8. User sees reward preview.
9. User opens Network Terminal.
10. User receives invite link.

## Clicker

Clicking is an activation ritual, not endless work.

| Mechanic | Start value |
|---|---:|
| Base click | 1 Compute |
| Session submit | every 10s or 50 clicks |
| Combo 1 | 10 clicks, x1.2 |
| Combo 2 | 25 clicks, x1.5 |
| Rare roll | 50 clicks, 2% |

## Idle

Generators produce resources over time.

```text
earned = rate_per_minute * elapsed_minutes * multipliers
```

Offline cap keeps balance controlled.

## Meta Progression

- Account Level;
- Atlas Rank;
- Contribution;
- Reputation;
- Network Power;
- Mastery;
- Season progress.

## MVP Missions

### AtlasRepo First Scan

Reward: `25 Knowledge`, `5 Contribution`, reward preview.

### Build Your Network

Reward ladder:

- invite 1 friend -> 250 Compute;
- friend reaches level 3 -> Trend Scanner;
- 3 active friends -> 1 Want2View research;
- 5 active friends -> 7 days AtlasRepo Pro.
